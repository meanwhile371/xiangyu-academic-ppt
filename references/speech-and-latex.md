# 逐页讲稿与配套 LaTeX

## 先确定讲述范围

区分选讲和逐页完整两种目标。当前用户要求每页都要有并允许超时时，完整性优先，不再沿用旧的时长限制。附录、参考文献、分工页也应有可朗读内容。视频页要写播放前的引入和播放后的承接，视频本体另记时长。

讲稿按照最终 PPTX 的真实页序，不以可能过时的内部页脚编号为准。每次增删或移动PPT页面后重建映射。至少记录实际页码、标题、讲述正文、视频或操作说明、估计时长。

推荐源稿格式：

```markdown
# 第1页 开场

这一页的可直接朗读正文。

# 第2页 研究问题

第二页正文，并自然衔接下一页。
```

运行 `scripts/check_slide_coverage.py --pptx <最终稿> --script <源稿.md> --require-all` 检查覆盖。它能发现缺页、重页、页序和空正文，不能代替人工核对科学内容或PDF渲染。

## 每页讲什么

用口语解释图中的问题、关键操作或证据、得到的认识，再引到下一页。理论页把符号读法、代入、展开、取期望和求和说清楚，不只朗读式号。参考文献页按研究主题说明各组文献与正文的联系，不需要机械念完每个DOI，但应有实质讲述。

写过渡时检查是否更换研究、任务、理论模型或评价指标。不得把原稿中用于9分钟选讲的跳页句带入完整稿。

## 时间估计

总时长 = 口述时间 + 视频时间 + 必要停顿和切页。估计参数是排练规划，不是经验实测事实。

可先按字数给出可调整范围，复杂公式页使用更慢语速，英文术语和数字考虑额外发音成本。展示采用的语速与停顿假设，给出范围，再用本人试讲校准。选讲稿需列出哪些页跳过；完整版若超时，应如实报告，不能用过快的假定语速迎合旧时长。

## 紧凑 PDF

LaTeX使用UTF-8，中文项目可选择ctex与XeLaTeX，字体与宏包兼容Overleaf。页码标题使用稳定层级，不因每张PPT强制换纸页。用适当行距和 `needspace` 防止标题孤立在页尾，正文不跨栏冲撞。正文和提示可在同页清楚区分，操作说明不朗读。

输出后检查PDF所有PPT页码、正文首尾、缺字、溢出和页面预览。源码包只包含主文件、章节、必要图像与文献，排除aux、log、缓存、凭证和私有绝对路径。编译检查要实际运行；未执行Overleaf在线编译时，只报告本地或桌面编译成功。

## 报告配套

报告与PPT可共享术语、图源和成员数据，页数不必相同。用户更名时同步题名、页眉、PDF元数据和正式文件名。分工表使用同一数据源，比例合计和人员对应关系分别核对。

摘要、目录、图目录、表目录的标题可按用户要求居中；正文和标题文字纯黑，原图保持其颜色。上标引文需要统一实际引用样式，并检查图注、表格及长文各处是否生效。
