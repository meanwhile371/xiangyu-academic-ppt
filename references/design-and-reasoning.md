# 排版与理论叙事

## 一页与一页之间的关系

每页都要说明一个具体问题，并让下一页有来由。为页面记录：进入时读者知道什么，本页新增了什么，离开时还有哪个问题。过渡句来自这一缺口，避免反复使用空泛的接下来。

概念与应用汇报可采用：生活问题 → 协作约束 → 定义与分类 → 一轮更新 → 优化目标 → 算法 → 条件下的理论 → 误差来源 → 修正机制 → 信息风险 → 应用证据。它是一种参考弧线，不能强制覆盖所有论文。

跨论文切换时标明研究与任务变化。架构图只回答怎样协作，训练曲线回答某种指标，独立测试回答另一层泛化问题，真实部署效益需要相应证据。

## 数学原理到风险的桥梁

先定义符号和目标，再给算法。固定经验目标与同质总体模型要分别说明；有限本地抽样对本地目标无偏，不自动对共同总体无偏。

讲解收敛时遵循实际计算：

1. 从光滑性写出位移的线性项与二次余项。
2. 代入精确负梯度，合并步长系数，指出取值条件。
3. 加入随机噪声，展开平方，说明条件无偏为什么消去交叉项。
4. 多端平均的方差改善还需要交叉协方差条件。
5. 跨步求和，展示中间项相消与目标下界如何进入。
6. 区分凸目标次优差距和非凸驻点指标。
7. 回到本地多步，展开轨迹并加减轮初梯度，解释额外残差。
8. 再讨论目标差异、参与抽样和算法修正，最后转向交换更新的隐私风险。

这组步骤仅是讲解模板，具体公式、符号和充分条件必须来自当前原文或逐步核实的推导。不能把简化SGD教学式当作完整FedAvg定理。

比较上界时同时对齐算法、假设、预算、输出点和指标。步数K、epoch数E、通信轮数、传输字节与墙钟耗时不能混用。目标权重p和包含概率π、原表异质性常数与本稿学习率也不能混同。

## 高密度排版

用户参考页的实际字号、内容块宽度、行距和字框间隔是模板约束的依据。用网格、对齐线、图文比例和统一层级组织密度；不要用缩小整稿字号解决溢出。

大面积空白先追查原因：文字过少、图裁切不当、画幅不合适还是布局层级错误。优先调整，再考虑加入能解释内容的图。重复句、无关思维图与装饰卡片不增加有效信息量。

图例、坐标轴、色条、标题、正文和来源各有独立区域。显示顺序与视觉顺序一致，图形元素不穿过文字。每个区域的宽度足够呈现内容，必要时拆页。

封面要有明确题名、视觉主体和必要的成员信息。沿用已接受的图与标题关系，成员信息不能压住主图。语言、黑白或彩色按本次要求执行，不擅自用新的封面风格替换已批准版本。

## 中文表达

优先用短句与连接清楚的段落。首次出现的术语与符号给出定义，后文统一。内容讲清成立条件即可，不在每页重复冗长的免责语。也不能为了去掉防御性表达而删掉实质假设、限制或不确定性。

研究类材料的讨论应直接说明证据能支持什么及其具体边界。课程汇报无需冒充原创研究，也无需为排版修订追加一套无关实验。
